LIVE DATA PATH

One frame, end to end

Select a stage for details
  1. 01Camera

    Camera frame → JPEG. Browser permission and capture errors are shown in Live View.

  2. 02YOLO11n

    JPEG frame → model detections, classes, confidence and pixel boxes. Missing model weights produce an explicit error.

  3. 03ByteTrack-style

    Detections → per-session IDs and lifecycle events using score tiers and IoU association.

  4. 04Depth Anything V2

    RGB frame → normalized relative depth map. Per-object central-box median → NEAR, MID-RANGE, FAR or UNKNOWN.

  5. 05Spatial

    Boxes and relative depth → horizontal and vertical regions plus pairwise image-space relationships.

  6. 06Scene graph

    Current objects → graph nodes and spatial-relation edges for this frame.

  7. 07Memory

    Tracked observations → current/recent objects, continuity and scene changes within this session.

  8. 08Voice Q&A

    Scene memory → grounded answers and concise narration. Browser playback is only reported after speech events.

  9. 09HITL review

    Frame and object feedback → persistent SQLite record and audit event. Corrections do not change model weights.

    DEPTH ANYTHING V2

    Relative depth estimation

    Waiting for a frame

    A pretrained depth model's actual per-frame output will be shown here; no brightness or size heuristic is used.

    LOW · farther in this frameHIGH · nearer in this frame

    Object categories use the median prediction inside the central 50% of each detected box: NEAR · MID-RANGE · FAR · UNKNOWN. These are relative categories, never metres.

    Model input and output

    BYAKU converts the captured BGR frame to RGB, lets the Depth Anything V2 image processor resize and normalize it, then resizes the prediction to the original frame and normalizes it within that frame. A selected object highlights its box and sampled region.
